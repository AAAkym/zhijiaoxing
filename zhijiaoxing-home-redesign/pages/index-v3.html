老师,这道题我不太理解:求 f(x) = x² + 2x - 3 的极值,我算出来极值点是 x = -1,但不知道怎么判断是极大还是极小?

你求出的极值点 x = -1 是正确的!判断极大极小有两种方法:

方法一:二阶导数判别法
f'(x) = 2x + 2 → f''(x) = 2
f''(-1) = 2 > 0 → 极小值
方法二:一阶导数变号法
x < -1: f'(x) < 0 (递减)
x > -1: f'(x) > 0 (递增)
→ 极小值, f(-1) = -4

你的错因诊断:概念理解偏差 — 知道求极值点但不清楚判别方法。建议练习 3 道同类题型巩固。

明白了!二阶导数大于0就是极小值。那如果 f''(x) = 0 怎么办?
