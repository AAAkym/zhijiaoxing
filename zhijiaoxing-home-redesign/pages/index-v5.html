老师,求 f(x) = x² + 2x - 3 的极值,我算出极值点 x = -1,但不知道怎么判断极大还是极小?

极值点 x = -1 正确!判断极大极小有两种方法:

方法一:二阶导数 — f''(x)=2 > 0 → 极小值
方法二:一阶导数变号 — x<-1 递减,x>-1 递增 → 极小值 f(-1)=-4

错因诊断:概念理解偏差。建议练习 3 道同类题型巩固。
