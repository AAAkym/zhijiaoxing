# EduAI Pro 需求分析文档

## 1. 项目背景

EduAI Pro 是基于多智能体的自适应学习系统，面向高校及职业教育场景。系统针对传统学习平台学习路径固定、个性化辅导不足、教师难以及时掌握学生差异等问题，采集学习行为数据，动态识别知识薄弱点并推荐适配资源。

## 2. 用户角色

| 角色 | 核心需求 |
|---|---|
| 学生 | 查看学习路径，获得个性化资源、练习和答疑，跟踪学习进度 |
| 教师 | 查看班级学情，管理课程资源，识别薄弱知识点并进行教学干预 |
| 管理员 | 管理用户、课程、权限、系统配置和运行数据 |

## 3. 功能需求

1. 用户与权限：注册、登录、角色权限、个人资料和安全设置。
2. 学习数据采集：记录做题正确率、学习时长、知识点错题、资源访问和交互反馈。
3. 学情画像：根据多维行为数据计算知识点掌握度，形成可解释的动态画像。
4. 多智能体协同：诊断智能体识别问题，推荐智能体选择资源，助教智能体提供解释，调度智能体编排任务。
5. 自适应资源推荐：根据掌握度和学习状态调整内容难度与学习顺序。
6. 学习空间：展示课程、任务、资源、进度和阶段反馈。
7. 教学管理：教师维护课程与资源，查看班级分析和个体差异。
8. 质量与安全：记录模型调用、审核生成内容、控制访问权限并保留操作日志。

## 4. 非功能需求

- 可用性：登录、课程浏览和学习记录等基础功能稳定可用。
- 性能：常规页面及时响应，模型调用具备超时、重试和失败提示。
- 可扩展性：智能体、资源类型和课程模块可独立扩展。
- 安全性：遵循最小权限原则，敏感配置隔离，输入校验和日志审计。
- 可解释性：推荐结果和画像变化能够追溯到学习行为依据。

## 5. 首季度验收口径

完成需求调研、总体功能分析和基础业务流程设计；完成前后端工程搭建、数据库初步设计、用户登录、基础学习数据采集以及首页、个人中心、学习空间等基础页面；完成小范围内部测试记录。学情诊断和个性化推荐的深度优化列入下一阶段。
