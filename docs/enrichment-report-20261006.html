03已知问题与折衷（如实标注）

  • T1 词云偶发空白（交接遗留）：错题本父组件数据刷新导致统计面板周期性重挂载，词云绘制窗口被掐断；库本身手动调用已验证可画。缓解：切回 tab 可触发重绘。
  • T2 方案变更：FullCalendar 弃用 → 零依赖手写 MonthGrid。理由：React 19 下适配器整树崩溃 + v6/v7 生态断裂 + locales 导入在 Vite 解析报 missing。月历核心价值（规划铺上日期网格）完整保留。
  • T3 交接代码带 bug：knowledge_tags 为 JSON 字符串且含空格，genanki 标签校验 500；已修（_safe_json_loads + 空白转下划线）并实测导出。
  • T5 弃 pdfmake：默认 vfs 无中文字体；改用打印视图（@media print 隔离 + window.print 存 PDF）。
  • T6 OCR 精度：best_int 小模型包（chi_sim 1.7MB / eng 2.9MB），中英文混排会有空格/标点噪点——题干始终经人工核对后才保存，OCR 仅预填。离线可用。
  • T7 白板不持久化：elements 纯转发不落库（设计如此——白板是会话内协作工具，非归档数据）；后进房间者看到的是新笔迹而非历史画面。

04环境基建修复（本次新增工程资产）

  • .night-run/shot.py：playwright + 系统 Chrome 截图器——UI 表单登录（写 localStorage currentUser，走真实门禁）→ hash 路由 → 点击/滚动/等待步骤 → 截图；内置 ensure_backend 自愈（端口无监听则 WMI 拉起）。
  • 后台进程存活问题：本会话 spawn 的进程会被随调用回收（nohup/Start-Process/WMI-cmd 均被收割，schtasks 亦被控制台终止 0xC000013A）；唯一稳定方案是 pythonw.exe（无控制台） 经 WMI 拉起——已在 .night-run/start-backend-wmi.ps1 固化，后端/截图脚本均自愈复用。
  • .night-run/ws-sync-test.js：双 socket.io 客户端白板转发实测脚本（登录→同房→emit→断言对端收到）。
  • 网络实况：github.com git push 间歇可达（夜推成功一次）；jsdelivr CDN 对 bash 不可达但对浏览器可达——T6 因此改本地自托管。
