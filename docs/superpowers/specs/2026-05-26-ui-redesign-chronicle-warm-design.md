# UI 重构设计文档：Chronicle 结构 + 温暖灵魂

> 日期：2026-05-26
> 参考页面：https://chroniclehq.com/?ref=godly
> 设计方案：方案 A — Chronicle 结构 + 温暖灵魂

## 1. 设计目标

基于 Chronicle HQ 的页面结构骨架，结合智教星品牌温暖米色+金色视觉语言，重构首页、登录页、欢迎引导页三个公共页面。

## 2. 设计系统

### 2.1 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#faf8f5` | 温暖米白 |
| 卡片/表面 | `#ffffff` | 纯白 |
| 强调色（主） | `#d4a853` | 金色 |
| 强调色（辅） | `#2a9d8f` | 青绿 |
| 强调色（暖） | `#c45a3e` | 赤陶 |
| 文字主色 | `#2d2a26` | 深棕黑 |
| 文字副色 | `#6b6560` | 中灰棕 |
| 文字弱色 | `#9a9590` | 浅灰棕 |
| 分割线 | `#e8e4df` | 暖灰 |

### 2.2 字体

- 标题：Plus Jakarta Sans, 600-700
- 正文：Inter, 400-500

### 2.3 间距规范

- 最大宽度：1200px
- 模块间距：100px（桌面）/ 64px（移动端）
- 内边距：24px（桌面）/ 16px（移动端）

### 2.4 圆角规范

- 按钮：10px
- 卡片：16px
- 图片：12px

### 2.5 阴影层级

- 卡片默认：`0 1px 3px rgba(45,42,38,0.06)`
- 卡片悬停：`0 12px 32px rgba(45,42,38,0.10)`
- 产品截图：`0 24px 64px rgba(45,42,38,0.12)`

## 3. 首页（LandingPage）— 7 模块

### 模块 1：导航栏
- 左侧：金色圆角 Logo + "智教星" + "EDUSTAR"
- 中间：4 个导航链接
- 右侧：登录 Ghost + 金色 CTA
- 滚动时：`bg-[#faf8f5]/90 backdrop-blur-xl` + 暖灰分割线

### 模块 2：Hero 首屏
- 垂直居中，max-w 800px
- 小标签 "2026 · AI教学数字孪生" 金色胶囊
- 大标题 56-72px，金色强调
- 副标题 18px
- CTA：金色主按钮 + 描边次要按钮
- 产品演示图：90% 宽，圆角 16px，大阴影

### 模块 3：使用场景横向滚动
- 6 卡片横向排列，280px 宽
- 金色系渐变缩略图 + 文字标签
- 水平滚动 + snap

### 模块 4：社会证明条
- "受到 5000+ 团队信赖"
- Logo Marquee 无限滚动，30s 一圈

### 模块 5：核心功能展示
- 4 个功能点左右交替
- 文字侧：小标签 + 标题 32px + 描述
- 图片侧：圆角截图 + 阴影
- 功能间 1px 暖灰分割线

### 模块 6：企业级特性网格
- 2×3 网格
- 金色底图标 + 标题 + 描述
- 悬停上浮 4px + 金色边框

### 模块 7：用户评价区
- 标题 40px 居中
- 自动轮播 5s + 手动切换
- 引号 + 斜体引用 + 分隔线 + 头像 + 姓名 + 职位

## 4. 登录页（LoginPage）— 左右分栏

### 左栏（55%）
- 背景 `#faf8f5` + 金色渐变光晕
- 居中：Logo + "智教星" + 品牌标语
- 底部：3 个核心价值标签

### 右栏（45%）
- 纯白背景
- 居中表单：标题 + 输入框 + 角色选择 + 登录按钮
- 输入框暖灰边框，聚焦金色
- 登录按钮金色填充

### 移动端
- 单栏，品牌区折叠为顶部小条

## 5. 欢迎引导页（WelcomeGuide）— 沉浸式

### 布局
- 全屏，`#faf8f5` 背景 + 金色渐变
- 顶部：进度条（金色）+ 跳过按钮
- 中间：每步全屏场景
  - 开场：Logo + 大标题
  - 概念：3 核心能力卡片
  - 功能：左右交替展示
  - 结尾：CTA
- 底部：上/下一步 + 步骤指示器
- AnimatePresence 切换

## 6. 动效规范

| 动效 | 触发 | 参数 |
|------|------|------|
| fade-in + slide-up | 模块进入视口 | y:30→0, opacity:0→1, 0.6s, ease:[0.22,1,0.36,1] |
| stagger children | 网格/列表 | 每项延迟 0.1s |
| hover lift | 卡片悬停 | y:-4px, 0.3s |
| button scale | 按钮悬停 | scale:1.02, 0.2s |
| marquee | Logo 轮播 | x:0→-50%, 30s, linear, infinite |
| carousel | 评价切换 | x:±40px, opacity, 0.4s, easeOut |

## 7. 响应式断点

- 移动端 < 768px：单列，标题 40px
- 平板 768-1024px：2 列，标题 56px
- 桌面 > 1024px：完整布局，标题 72px
