## 一、系统概述

智教星是一个基于 React + Flask 构建的 Web 应用，采用前后端分离架构：

| 组件 | 技术栈 | 说明 |
|---|---|---|
| **前端** | React 19 + Vite + Tailwind CSS | 单页面应用（SPA），端口 5173 |
| **后端** | Flask + Python 3.11 | RESTful API，端口 5000 |
| **缓存** | Redis 5.0（可选） | Celery 任务队列，端口 6379 |
| **AI 模型** | 讯飞 Spark 星火大模型 | 核心 AI 能力（赛题要求） |

## 三、快速启动（推荐）

### 方式一：一键启动脚本

#### Windows 系统

双击运行 `启动系统.bat`，脚本将自动完成以下操作：

1. 检测 Python、Node.js 环境
2. 创建 Python 虚拟环境
3. 安装前后端依赖
4. 启动后端服务（端口 5000）
5. 启动前端服务（端口 5173）
6. 自动打开浏览器访问系统

#### Linux/macOS 系统

```bash
# 添加执行权限
chmod +x 启动系统.sh

# 运行启动脚本
./启动系统.sh
```

### 方式二：Docker 一键启动（推荐给评委）

#### Windows 系统

双击运行 `Docker一键启动.bat`

#### Linux/macOS 系统

```bash
chmod +x Docker一键启动.sh
./Docker一键启动.sh
```

**Docker 启动优势**：
- 一键启动，无需手动配置环境
- 自动安装 Python、Node.js、Redis
- 环境一致性，避免版本冲突
- 评委无需了解技术细节

## 四、手动启动（详细步骤）

### 4.1 后端启动

#### Windows PowerShell

```powershell
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt

# 配置环境变量（复制示例配置）
copy .env.example .env

# 编辑 .env 文件，填入 Spark API 密钥
# SPARK_API_PASSWORD=your_api_password_here

# 启动后端服务
python src/main.py
```

#### Linux/macOS

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env 填入 Spark API 密钥
python src/main.py
```

### 4.2 前端启动

```bash
# 进入前端目录
cd frontend

# 安装 pnpm（如果未安装）
npm install -g pnpm

# 安装依赖
pnpm install

# 启动开发服务器
pnpm run dev
```

### 4.3 访问系统

打开浏览器访问：**http://localhost:5173**

## 五、Docker 部署详细说明

### 5.1 Docker 环境准备

| 系统 | 安装方式 |
|---|---|
| Windows | 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop) |
| macOS | 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop) |
| Linux | `curl -fsSL https://get.docker.com | sh` |

### 5.2 配置环境变量

```bash
# 复制配置文件
copy .env.docker.example .env   # Windows
cp .env.docker.example .env     # Linux/macOS

# 编辑 .env 文件，填入以下必填项：
SPARK_API_PASSWORD=your_spark_api_password_here
```

### 5.3 Docker 常用命令

| 命令 | 说明 |
|---|---|
| `docker-compose up -d` | 启动所有服务 |
| `docker-compose down` | 停止所有服务 |
| `docker-compose logs -f` | 查看实时日志 |
| `docker-compose restart` | 重启所有服务 |
| `docker-compose ps` | 查看服务状态 |

### 5.4 访问地址

Docker 启动后访问：**http://localhost**（nginx 代理，端口 80）

## 九、常见问题排查

### Q1: 后端启动报错 "ModuleNotFoundError"

**原因**：依赖未安装或虚拟环境未激活

**解决方案**：
```bash
cd backend
.\venv\Scripts\Activate.ps1  # Windows
pip install -r requirements.txt
```

### Q2: 前端无法连接后端 API

**原因**：后端未启动或端口冲突

**解决方案**：
1. 确认后端在 `localhost:5000` 运行
2. 检查 `frontend/.env.development` 中 `VITE_API_BASE_URL=/api`
3. Vite 代理已自动配置

### Q3: AI 功能返回空响应

**原因**：Spark API 密钥未配置

**解决方案**：
编辑 `backend/.env`，填入有效的 `SPARK_API_PASSWORD`

### Q4: Docker 启动失败

**原因**：Docker 未安装或 .env 未配置

**解决方案**：
1. 安装 Docker Desktop
2. 复制 `.env.docker.example` 为 `.env`
3. 填入 `SPARK_API_PASSWORD`

### Q5: 3D 知识图谱渲染卡顿

**原因**：浏览器 WebGL 未启用

**解决方案**：
1. 使用 Chrome/Edge 最新版
2. 检查 `chrome://gpu` 确认 WebGL 已启用
3. 节点数 > 150 时自动降精度优化
