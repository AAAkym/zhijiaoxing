# 智教星品牌符号：星瞳

这版改成更现代、更克制的品牌符号方向：不解释功能，不堆教育元素，而是创造一个能被单独记住的抽象印记。

## 设计关键词

- **星**：回应“智教星”，但不使用传统五角星。
- **瞳**：中心留白像智能系统的观察、聚焦与理解。
- **四向光瓣**：形成稳定、对称、好缩放的现代科技品牌轮廓。
- **单一主体**：SVG 里只有一个主体 `path`，导入 Figma、Illustrator、PPT 后就是一个整体图层。

## 文件

- `zhijiaoxing-symbol.svg`：主符号文件，单一主体图层。

## 使用建议

主色已改为贴合前端暖色调的品牌渐变：`#F8C66A → #F59E0B → #C7772E`。它对应页面中大量出现的米色背景、amber/orange 强调色，比冷蓝紫更适合当前系统的温暖教学气质。

封面、启动页、PPT 中不要给它加复杂装饰，留足空白，让符号自己成为识别点。
